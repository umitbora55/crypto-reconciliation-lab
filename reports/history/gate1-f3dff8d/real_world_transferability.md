# Real-world transferability

The completed local measurements are laboratory evidence. No row in this program is labelled REAL_INSTITUTIONAL_TRANSACTION. Treasury and SEC acquisition was attempted but blocked; therefore no current result demonstrates real-source cash arithmetic, adapted real-data integration or semi-synthetic detection on real historical rows.

## Four data classes

| Data class | Meaning and valid use | Observed status in this task |
|---|---|---|
| REAL_PUBLIC_DIRECT | Official historical quantities are used in their actual source grain and an independently meaningful identity is verified, such as same-day TGA opening + deposits − withdrawals = closing in the published units. | **DATA_UNAVAILABLE / NOT_RUN**. Zero real equalities verified; supplied example arithmetic is not counted as retrieved evidence. |
| REAL_PUBLIC_ADAPTED | Actual source quantities are transformed through an explicitly reviewed mapping into a narrower research model; changes in grain, units, revision and completeness semantics remain visible. `ADAPTED_REAL_AGGREGATES` is a descriptive subtype, not institutional transaction truth. | **NOT_RUN**. Adapter code has synthetic contract tests; no source mapping was accepted without official documentation. |
| SEMI_SYNTHETIC_INJECTION | Known changes are introduced into actual source rows, with labels derived solely from those controlled changes. Detection metrics apply only to the injection design. | **NOT_RUN** because no real source base was acquired. Synthetic fixtures were not relabelled semi-synthetic. |
| FULLY_SYNTHETIC | Every quantity, event, correction, label or manipulated report is generated or explicitly specified for a test. | **EXECUTED**: protected-suite fixtures, 264 finite property cases, 33 resilience checks, public-adapter unit tests, mutation witnesses and deliberately narrower benchmark inputs. |

The scope registry's legacy `SYNTHETIC` label maps to FULLY_SYNTHETIC here. A downloaded error page would be request evidence, not a financial dataset; these attempts received no origin body. Acquisition-integrity PASS means the intended request outcomes and retained bytes are accounted for, not that a real financial equality passed.

## What transfers as an engineering method

Exact integer/Decimal arithmetic, explicit economic and knowledge cuts, preserving prior observations, separating missingness from mismatch, documenting revisions, isolating generated labels from the calculation, and requiring an independent expected inventory are useful design practices. Their relevance can be assessed without claiming that a particular institution uses or lacks them.

The finite experiments show that these particular implementation paths behave as reported for the declared inputs on the tested Linux/Python configurations. They do not establish that the implementation's source identity, manifest conventions, finality, correction rules, time authority or custody ownership match another institution. Those contracts require a separate gap analysis and data-owner review.

A two-source reconciliation pilot also needs evidence independent of both producers. Hashes and signatures can bind records without proving economic truth. A shared wrong answer remains possible when all comparisons use the same engine or rely on mutually consistent but incomplete source assertions. The recorded replay feature deliberately claims same-engine reconstruction only.
