The unchanged financial engine/watchdog is distinct from these validation-tool
repairs. Each finding retains actual RED and subsequent acceptance evidence.

  preservation tests need three explicit input projections to restore old bytes
  before their original comparisons; all three changed files are independently
  pinned and reversible. Historical contracts and 875 IDs remain fixed.

  Python 3.12/3.14. The3.14 preflight failed before test execution. Explicit empty

  early3.12 attempt was stopped and retained; fresh builds are the acceptance runs.

  sources. Exact source pins, executed-ID equality, zero xfail/xpass/skip counters

  trailer count/quantity controls repair parsing without counting trailers as
  financial observations. Automatic SEC acquisition now requires the actual
  official landing-page ZIP hyperlink before downloading.

  from raw trial status, and accepted empty proof objects. Saved counterexamples
  demonstrate those false-success paths; derived-statistic and exact proof/roster
  validation are required before canonical timing evidence is accepted.

- The review packager initially missed untracked source, mutable worktree bytes,
